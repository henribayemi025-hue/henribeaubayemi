## Ce que c'est
Cinq dépôts : un extracteur de fiches Google Maps, un automate de contenus (YouTube Shorts, bot, affiliation, prospection), Agent S (un agent qui voit l'écran et clique), Gitingest (un dépôt entier transformé en un seul texte pour une IA) et Fabric (une bibliothèque de consignes réutilisables).

## Ce qui est vraiment utile pour Finjaro et Léo
Gitingest : exactement ce qu'il faut pour que les agents de l'atelier lisent un dépôt GitHub en entier (connecteur GitHub par entreprise). Fabric : un modèle pour ranger les compétences des agents en « motifs » nommés. Agent S : rejoint la demande « les agents prennent la main sur l'ordinateur ».

## Pour quels agents de Léo
Forge et Claude (Gitingest dans l'atelier) ; Mentor (Fabric comme modèle de compétences) ; Alpha (Agent S, prudence).

## Compétences à tirer (pour Mentor)
**Lire un dépôt d'un coup** — Forge — Avant de modifier un projet, en faire un résumé texte (arborescence + fichiers clés + nombre de jetons) ; ne jamais envoyer à l'IA des fichiers secrets (.env, clés).

## Limites, risques, prudence
Google Maps Scraper : extraire Google Maps va contre ses conditions d'utilisation et touche des données de personnes — mis de côté. MoneyPrinterV2 : proche de la fiche 32, publication automatique non. Agent S : un agent qui clique sur un ordinateur demande l'accord explicite à chaque action.

## Verdict
Retenu : Gitingest (atelier), Fabric (forme des compétences). Mis de côté : Google Maps Scraper.
